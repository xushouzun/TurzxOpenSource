# 初回の画面出力

7 インチ `USB\VID_1CBE&PID_0070` を例にします。他のモデルは[互換性記録](compatibility.ja.md)を参照してください。

1. Releases から `TURZX-Studio-win-x64.zip` をダウンロードして展開し、`TURZX.WinUsbDisplay.Studio.exe` を直接実行します。プレビュー、レイアウト、オフライン設定にディスプレイ接続は不要です。
2. デバイスマネージャーの「プロパティ → 詳細 → ハードウェア ID」で VID と PID を確認し、「ドライバー → ドライバーの詳細」でデバイスが `winusb.sys` にバインドされていることを確認します。ドライバーが必要な場合は、[TURZX](https://www.turzx.com/) またはデバイス販売店から該当するハードウェア ID の署名済み WinUSB ドライバーを入手してください。動作するドライバーが既にある場合は次の手順へ進みます。同じサイズのモデルでもプロトコルが異なる場合があります。
3. ディスプレイを使用しているベンダーソフトを終了します。**メディア → 前景ソース** で **画像を選択** に切り替え、**参照** から JPEG または PNG を選択します。背景をクリアして **再生開始** をクリックします。実機の画面と向きを確認し、**再生停止** をクリックします。

ディスプレイに Windows デスクトップが表示されている場合は、**デバイスコマンド** で `SWITCH_TO_MONITOR_MODE` を選択し、デスクトップモード機器を更新してシリアル番号で対象を選び、**USB副画面に戻す** をクリックします。デスクトップモードには同梱の TURZX ディスプレイドライバーが必要です。Windows に画面が表示されない場合は **詳細設定** のデスクトップモード ドライバー欄からインストールしてください。詳細は[モード切替の手順](win207-protocol.ja.md)を参照してください。

デバイスマネージャーでは USB 副画面モードとして認識されているのに Studio の一覧が空の場合、ドライバーベンダーに登録されている WinUSB インターフェイス GUID を確認してください。カスタム GUID を使用する場合は `%LOCALAPPDATA%\WinUsbDisplay\studio-settings.json` の `InterfaceGuid` フィールドを設定し、CLI では `--interface-guid <GUID>` を指定します。
