### Win207 の注意事項

`1CBE:0035` は WinUSB/Win207 の 3.5 インチディスプレイです。`1CBE:A021` は 2.1 インチ円形のバリエーションです。

同じサイズでもパネル、ファームウェア、PID が異なる場合があります。デバイスマネージャーのハードウェア ID で確認してください。6.2 インチ `C062`、9.2 インチ `0092`/`A092`、11.3 インチ `0113` は出力サイズと異なるベンダーテーマキャンバスを使用しますが、Studio は表のサイズで出力します。`0124`、`0126`、`0145` はネイティブの横向きストリップです。4.5 インチパネルはネイティブで 1024 × 768 の横向きです。その他の向きは **メディア** ページで設定します。

6.8 インチ（`1CBE:0068`）は、20 FPS、0°、背景なし、既定レイアウトの HTML ライブ出力でのみ H.264 分割転送を使用し、FFmpeg が必要です。その他の構成ではフレームごとの画像を使用し、フレームレートは低くなります。

12.3 インチの向きは **メディア** ページで設定します。Windows デスクトップモードから Studio の出力に戻すには、**デバイスコマンド** で `SWITCH_TO_MONITOR_MODE` を選択し、デバイスのシリアル番号で対象を選んで **USB副画面に戻す** をクリックします。デスクトップモードでモニターとして使用するには、同梱の TURZX ディスプレイドライバーも必要です。未インストールの場合は **詳細設定** のデスクトップモード ドライバー欄からインストールしてください。

## 対応シリアルディスプレイ

| ディスプレイ | USB VID:PID | インターフェイス | ネイティブキャンバス |
| --- | --- | --- | --- |
| 3.5 インチ | `1A86:5722` | CH340 シリアル（`USB35INCH`） | 480 × 320 |

3.5 インチシリアルディスプレイ（`1A86:5722`）は WinUSB/Win207 の `1CBE:0035` とは別のデバイスで、WinUSB/Win207 ではなく CH340 を使用します。Studio は `USB35INCH` で認識し、他の前景ソースを隠して **ネイティブテーマ** のみを表示します。任意の `.data` テーマを選択すると、Studio がローカルでレンダリングし、フレームをシリアル経由で送信します。レジスタパケットとフレーム形式は[シリアルプロトコル](serial-protocol.ja.md)を参照してください。

- Studio には 3 つの中性的な工場出荷テーマ（`默认主题-深蓝`、`默认主题-深空`、`默认主题-灰岩`、480 × 320）が同梱されています。テーマのキャンバスは 480 × 320 または 320 × 480 である必要があり、他のサイズは拒否されます。
- Studio は JSON の `.data` テーマのみを読み取ります。旧形式のバイナリ `.data` は事前に変換してください。
- 輝度と向きは **メディア** ページで設定します。輝度は 0～100%（0% が最も暗く、100% が最も明るい）、向きは 0° または 180° です。変更は再生中に反映され、向きを変更するとフレームが再送されます。
- プレビューと出力にはテーマのサンプル値を使用します。センサーの実データは読み取りません。
