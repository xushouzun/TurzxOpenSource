# 内置 HTML 预设 · Built-in HTML presets

安装 Chrome 或 Edge，在「媒体 → 前景来源」选择「HTML 实时渲染」，然后从示例场景下拉列表选择预设。未连接设备时也可预览。送屏时，选好设备后点击「开始播放」。

With Chrome or Edge installed, select **Render HTML live** in **Media** and choose a sample scene. Preview works without a display. To send it to hardware, select the display and start playback.
