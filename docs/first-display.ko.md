# 첫 화면 출력

7인치 `USB\VID_1CBE&PID_0070`을 예로 듭니다. 다른 모델은 [호환성 기록](compatibility.ko.md)을 참고하세요.

1. Releases에서 `TURZX-Studio-win-x64.zip`을 내려받아 압축을 풀고 `TURZX.WinUsbDisplay.Studio.exe`를 바로 실행합니다. 미리보기, 레이아웃, 오프라인 설정에는 디스플레이 연결이 필요하지 않습니다.
2. 장치 관리자의 "속성 → 세부 정보 → 하드웨어 ID"에서 VID와 PID를 확인하고, "드라이버 → 드라이버 세부 정보"에서 장치가 `winusb.sys`에 바인딩되었는지 확인합니다. 드라이버가 필요하면 [TURZX](https://www.turzx.com/) 또는 장치 공급업체에서 해당 하드웨어 ID용 서명된 WinUSB 드라이버를 받으세요. 정상 동작하는 드라이버가 이미 있으면 다음 단계로 진행합니다. 같은 크기의 모델이라도 프로토콜이 다를 수 있습니다.
3. 디스플레이를 사용 중인 벤더 소프트웨어를 종료합니다. **미디어 → 전경 소스**에서 **이미지 선택**으로 전환하고 **찾아보기**로 JPEG 또는 PNG를 선택합니다. 배경을 지우고 **재생 시작**을 누릅니다. 실제 화면의 이미지와 방향을 확인한 뒤 **재생 중지**를 누릅니다.

디스플레이에 Windows 데스크톱이 표시되면 **장치 명령**에서 `SWITCH_TO_MONITOR_MODE`를 선택하고 데스크톱 모드 장치를 새로 고친 뒤 일련번호로 대상을 선택하여 **USB보조화면으로 복귀**를 누릅니다. 데스크톱 모드에는 함께 제공되는 TURZX 디스플레이 드라이버가 필요합니다. Windows에 화면이 표시되지 않으면 **고급 제어**의 데스크톱 모드 드라이버 영역에서 설치하세요. 자세한 내용은 [모드 전환 안내](win207-protocol.ko.md)를 참고하세요.

장치 관리자에서 이미 USB 보조 화면 모드로 보이는데 Studio 목록이 비어 있으면 드라이버 공급업체에 등록된 WinUSB 인터페이스 GUID를 확인하세요. 사용자 지정 GUID를 사용하는 경우 `%LOCALAPPDATA%\WinUsbDisplay\studio-settings.json`의 `InterfaceGuid` 필드를 설정하고, CLI에서는 `--interface-guid <GUID>`를 사용합니다.
