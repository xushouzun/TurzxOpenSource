# 安全问题报告 / Reporting security issues

请针对最新预览版或当前默认分支报告安全问题。若托管仓库启用了 GitHub 私密漏洞报告，请在仓库的 **Advisories** 页面选择 **Report a vulnerability**。若入口不可用，请使用仓库维护者提供的私下联系方式。请勿在公开 Issue 或 PR 中提交漏洞细节、封包参数、设备序列号或私人路径。

报告请注明受影响的版本或提交、Windows 版本、受影响的组件及可复现的步骤。涉及硬件时请附上 VID:PID 和固件版本。如果找不到私下联系方式，可以发一个仅询问联系方式的 Issue。

Report security issues against the latest preview or the current default branch. If the hosted repository has enabled GitHub private vulnerability reporting, select **Report a vulnerability** on the repository’s **Advisories** page. If the button is unavailable, use a private contact method listed by the maintainers. Keep vulnerability details, command keys, device serial numbers and private paths out of public issues and pull requests.

Include the affected release or commit, Windows version, affected component, and reproduction steps. For hardware issues, include the VID:PID and firmware version. If you cannot find a private contact, open an issue asking only for the preferred contact method.
